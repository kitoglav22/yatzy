# Яцзы

Блокнот для подсчёта очков в Яцзы на двоих. Работает в Safari на iPad, без интернета после первого открытия.

Откройте https://kitoglav22.github.io/yatzy/ в Safari и выберите «Поделиться» → «На экран Домой».
История партий хранится на устройстве. Кнопка «Сохранить копию» выгружает её в файл.
