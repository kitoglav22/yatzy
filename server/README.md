# Бот Яцзы

Одна функция Yandex Cloud Functions (Node.js 18+, без зависимостей): `index.js`, точка входа `index.handler`.

- **Запросы приложения** (POST, тело JSON): `hello` (кто из комнаты играет из этого Telegram), `moved` (записана клетка или началась партия), `nudge` (кнопка «Поторопить»), `rating`. Каждый запрос подписан Telegram (`initData`), функция проверяет подпись токеном бота.
- **Вебхук Telegram**: `/start` и инлайн-режим `@k22_yatzy_bot` (приглашение из любого чата). Заголовок `X-Telegram-Bot-Api-Secret-Token` должен совпадать с `HOOK_SECRET`.
- **Таймер** раз в 10 минут: первое «твой ход» тем, кто был в приложении, и напоминания раз в сутки, не больше трёх на ход.

Данные бота лежат в той же базе Firebase в разделе `srv/`. Правила базы его не открывают, поэтому приложение туда не достаёт, а функция входит сервисным аккаунтом.

Переменные окружения: `BOT_TOKEN`, `FB_SA` (JSON ключа сервисного аккаунта Firebase), `HOOK_SECRET`. Необязательные: `FB_URL`, `APP_LINK`, `APP_ORIGIN`, `SELF_URL`.

После загрузки откройте ссылку функции с `?setup=<HOOK_SECRET>`: функция подключит себя как вебхук бота. Адрес функции записывается в `BOT_API` в `src/telegram.js`.

Тесты: `tests/bot.test.js` (сервер с поддельной базой и Telegram) и `tests/tgbot.test.js` (приложение вместе с ботом).
